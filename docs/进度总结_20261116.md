## 十一、随机种子系统（2026-11-16 下午 · 后半段）

### 11.1 功能

- **「＋ 添加随机种子」**：数量 1~50，一次批量生成；每张都重新随机挑模板
- **「随机表」**（双表设计）：
  - **表1**：左边**点位**（已校准 / 未校准两栏，勾选=参与筛选）；右边**建筑**（全局权重，默认 10，`0`=不参与），
    点建筑前面的 `▸` 展开**变体权重**（每个建筑独立一套）
  - **表2**：**夜晚 BOSS** / **缩圈**（勾选）
- **随机流程**：随机挑同地图类型的模板种子 → 遍历模板点位 →
  勾选的才随机（建筑按权重、变体按该建筑的变体权重）→ 没勾的**保持模板原样** → 模板没有的点位不出现
- **夜晚 BOSS 分晚**：第一晚只从官方第一晚集合（18 个）抽、第二晚只从第二晚集合（17 个）抽，**交集为空**
- **缩圈**：只在该地图类型自己的候选里选，1缩/2缩 分开取候选
- **组点**（大空洞 4 组）保持模板（必须成套），不参与建筑随机
- **开发者日志**：每次随机追加到 `work\random_log.jsonl`；随机表右下角「导出随机日志」生成
  `work\random_log_<时间>.json`（模板 pid / 建筑分布 / 变体分布 / 缩圈 / 两晚夜王 / 备注 / 警告）
