**attach 大小结论**
- 明说「小」→ 4 个：圣杯教堂 `002`、大商店 `004`、魔法师塔 `006`、野外BOSS `016`
- 没明说 → 一律「大」，代表本身自带一个大空位：遗迹 `003`、要塞 `007`、营地 `010`、教堂 `024`、毒池 `077`、锻造村 `078`、主城 `011`、大空洞上/下城 `075`/`074`
- 真·未知（监牢 `005`/`036`、粪金龟 `017`）→ 挂起，不参与匹配

**⚠ 铁律**：attach 大小必须和建筑对应，**不对应会出大问题**。编辑器校验器要拿这一列硬拦。

## 给编辑器定的规则

1. attach 与建筑必须匹配，只有标「小」的才允许进小据点 attach；其余按大。
2. 「同赐福」的一类（赐福 / 灵魂鹰 / 矿坑 / 任务 / 神授塔 / 灵魂气流）只认图标，不进种子编辑。
3. 宝箱、水晶由 eventFlag 决定，不在种子里摆。
4. 主城、大空洞上/下城是属性容器：只决定属性填什么，不当 attach 摆。
5. 监牢（未开/开启）大小未知 → 先不加，只保留可视（开启状态连可视都不用）。
6. 没研究透的（粪金龟）→ 挂起，界面灰掉，绝不让主人误点。
